# LSSP Audio Experiments

Python scripts for the audio experiments on fixed-delay reverberation and time-varying delay effects.

## Requirements

Install the required packages with:

```powershell
python -m pip install numpy scipy matplotlib
```

## Run

Place the selected input WAV beside the scripts, then run:

```powershell
python 5.1.py
python 5.2.py
```

The scripts write their processed WAV outputs in the same folder. Source recordings are in `Am/`.
